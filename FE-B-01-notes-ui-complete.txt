================================================================================
  WHAT WAS BUILT
================================================================================

Replaced the "Notes" placeholder text on the lead detail page with a full
notes CRUD feature. Notes appear as a dedicated card below "Lead Information"
on the lead detail page, supporting create, inline edit, and modal delete.

================================================================================
  FILES CHANGED / CREATED
================================================================================

CREATED:
  frontend/src/services/noteService.js
    API service wrapping /api/notes endpoints:
      GET  /notes?leadId=...     — list notes for a lead
      POST /notes                — create note { leadId, content }
      PATCH /notes/:id           — edit note { content }
      DELETE /notes/:id          — delete note

  frontend/src/stores/noteStore.js
    Zustand store (useNotesStore) with:
      - notes array + loading state
      - fetchNotes, addNote, updateNote, deleteNote actions
      - Stub data fallback (3 sample notes ready for S4-BE-B-02 wiring)
      - Optimistic updates: addNote inserts immediately, rolls back on error
      - Optimistic updates: updateNote/deleteNote snapshots prev state,
        rolls back if API call fails

CHANGED:
  frontend/src/pages/admin/LeadDetail.jsx
    - Imported useAuthStore (for author/role gating) and useNotesStore
    - Removed old inline "notes" string placeholder
    - Added "Notes" card below "Lead Information" with:
      - <textarea> + "Add Note" button (disabled when empty)
      - Notes list (newest first) from store
      - Each note: avatar, author name, fmt.ago timestamp, body text
      - Inline edit: Pencil icon swaps body to <textarea> + Save/Cancel
      - Delete: Trash2 icon opens .modal-backdrop + .modal confirm
    - Author/role gate: edit/delete buttons visible only for note author
      OR user with OWNER/ADMIN/SUPER_ADMIN role
    - "Add Note" quick action button now scrolls to notes section
      (instead of just toasting)

┌────────────────────────────────────────────────────────────────────────────┐
│                    INTERACTION FLOW (per note)                              │
│                                                                            │
│  CREATE:                                                                   │
│    Type in <textarea> → click [+ Add Note]                                 │
│      → useNotesStore.addNote({ leadId, content, author })                  │
│      → optimistic insert at top of list                                    │
│      → noteService.create() → POST /api/notes                              │
│      → on error: remove optimistic note, toast error                       │
│                                                                            │
│  EDIT:                                                                     │
│    Click ✎ (Pencil icon)                                                   │
│      → isEditing = true, show <textarea> + [Save] [Cancel]                 │
│      → [Save]: useNotesStore.updateNote(id, { content })                   │
│        → snapshot prev state → optimistic update                           │
│        → noteService.update() → PATCH /api/notes/:id                       │
│        → on error: revert to snapshot, toast error                         │
│      → [Cancel]: restore original content, exit edit mode                  │
│                                                                            │
│  DELETE:                                                                   │
│    Click 🗑 (Trash2 icon)                                                   │
│      → setDeleteConfirmNote(note) → show .modal                           │
│      → [Delete]: useNotesStore.deleteNote(id)                              │
│        → snapshot prev state → optimistic remove                           │
│        → noteService.delete() → DELETE /api/notes/:id                      │
│        → on error: revert to snapshot, toast error                         │
│      → [Cancel]: close modal, no change                                    │
